🐛 Trap 3: The extras1_runs Schema Bug

When summing deliveries against official match margins in RR's proprietary database, totals drifted by ~2.49 runs per match.

Auditing the raw columns revealed that extras1_runs does not store extra runs — it stores an extras type code (1=No-Ball, 2=Wide, 3=Leg-Bye, 4=Bye, 5=Other, 6=None, 7=Penalty).

Additionally, first_inn_revised_overs stores balls (114.0 = 19.0 overs). Correcting these was mandatory before computing any leverage values.
